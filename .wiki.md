# Project Summary
A browser-based quiz practice product that helps users study across learning domains, answer questions, review feedback, and see session results. It includes a redesigned, cloud-inspired home screen, responsive quiz experience, and browser-local progress. The frontend also contains blog pages with prerendering and sitemap support, plus authentication callback and error screens.

# Project Module Description
- **Home and quiz flow:** `Index.tsx`, `QuizViews.tsx`, and `quizData.ts` provide the landing page, domain practice, answer feedback, and results.
- **Authentication:** `AuthCallback.tsx` and `AuthError.tsx` handle authentication return and error states.
- **Blog:** Blog index and post pages render articles using shared layouts and Markdown support. Prerender scripts generate blog routes and sitemap data.
- **Shared UI:** `components/ui/` contains reusable interface components; `hooks/` and `lib/` provide shared state helpers, API access, configuration, and blog utilities.
- **Development safeguards:** Vite plugins and tests guard against unwanted hot-reload and entity-update behavior.
- **Design and reference attachments:** `DESIGN.md` records design guidance; `attachments/` contains the supplied UI source files.

- React and TypeScript
- Vite
- Tailwind CSS and reusable shadcn-style UI components
- Playwright for browser testing
- Markdown-based blog rendering and prerendering

# Usage
From the frontend directory:

```bash
cd app/frontend
npm install
npm run dev
```

Build and validate:

```bash
npm run lint
npm run build
```

Use the scripts defined in `package.json` for any additional tests or project tasks.
