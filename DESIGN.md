## Direction & Layout
CloudQuest Africa is an approachable Azure Fundamentals practice tool, not an enterprise admin dashboard. Supplied App.tsx establishes three screens and domain-based practice; supplied styles establish the existing blue/teal learning identity. Define a fresh cloud-campus direction: a light lavender hero with an oversized two-tone headline and an illustrative cloud orbit, above clear study-domain cards. White navigation, off-white main background, purple accents, charcoal type. Content width 1160px, hero 60/40 split, domain cards three columns, lower study panel 65/35. Section gaps 36px, card gaps 18px, desktop gutters 40px. Desktop >=1024px, tablet 640–1023px uses smaller hero illustration and two columns, mobile <640px stacks content with 20px gutters and 40px headline. Required: a memorable hero, visible domain selection, clear primary action, honest progress. Avoid dark gradient dashboards, glow borders, invented social proof, stock photography, and decorative navigation that does nothing.

## Shared Patterns & States
Header: cloud brand, real Practice and My progress section anchors, AZ-900 badge. Hero: exam eyebrow, large title, supporting paragraph, primary quiz action and text link to domains, compact learning-benefit row; CSS cloud orbit is supplementary. Domain card: icon badge, exam weight, title, description, question count, full clickable selection with visible selected check and purple border. Selection state must be keyboard accessible. Practice panel: selected-domain dropdown plus Start practice; progress panel uses actual browser history and explicit zero state. Quiz: question counter, progress bar, large question, four numbered answer rows, clear correct/incorrect feedback and explanation, Next disabled until answered. Results: score, domain breakdown, mistakes, retry/change domain. Buttons 44px minimum; visible 3px purple focus ring with offset; readable contrast; disabled actions still readable. Hover uses border/color changes and at most 2px lift over 180ms ease; reduced-motion disables transforms. Announce answer feedback and storage errors; keep content visible immediately. Local storage is optional and errors must not prevent practice.

## Media
This is an operational education interface: external imagery is not necessary. Build the cloud-orbit composition using CSS cloud silhouettes, dashed orbit lines, and lucide Cloud/ShieldCheck/Layers icons; abstract vector/CSS substitutes are acceptable here because they express the cloud subject without claiming to show a real Azure product. Hero illustration right aligned with ample clear space, no text overlay, hidden on small mobile when space is constrained. No fabricated student avatars or testimonial imagery.
